Read-only source review on 2026-11-11 against the development tree based on `021d3a4`; production and QA owners are still changing this tree. This is an interim review, not a completion claim. ## Findings sent to the owners

1. **Live jumpjet altitude and landing compression are absent in the reviewed tree.** `scene/battle.js:prepareUnit` uses `world(vx,vz)` without `jumpjetHeight`. `foundry/scene-rigs.js` then supplies terrain-level ground and `noPlant:false`, treating the motion as grounded walking; `pose.land` compression only applies outside the world scene. `scene/combat.js` adds exhaust, which does not supply lift. Restore the existing jump height on the world root, airborne leg handling, and landing compression, preserving the action rules. Capture and assert a real jump, including its landing.
2. **Mortar has a pose and socket but no presentation trigger.** `poseBehemothMortar` preserves the existing .95-second recoil/emitter timing and 2.1-second pose. `scene-rigs.js` accepts `pose.mortarAge`, but the reviewed runtime produces none and never consumes the `behemoth-mortar` FX profile. The original explicitly describes a future body skill with no damage rule. Complete a presentation-only cue and fixture, or clearly record this restricted interpretation; do not invent a playable damage action to satisfy the checkbox.
3. **Timing metadata remains ambiguous.** `docs/phase2-weapon-mapping.md` correctly explains production-rule compatibility. `scene/weapon-fx.js` still says integration is pending and lists the reference rifle/missile/pellet numbers rather than actual production beats. Those arrays are not used by `combat.launch`, which consumes logical contacts. Label them as reference-only or reconcile them with the production mapping before using them as reviewer evidence.
4. **Missile counter cue needs explicit evidence.** `qa/scene-combat.cjs` proves pending-command lockout, which differs from missile launchers being unable to counter. Existing Workshop text and reaction availability survive, but a new-layer visual cue is not established by that assertion. Verify the intended cue with the real launcher and a legal free-hand counter where applicable; preserve the existing reaction rules.
