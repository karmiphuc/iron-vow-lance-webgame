# Phase 4 hangar preparation

`dist/scene/hangar-fixture.html` is a development-only fixture for the Phase 4 scene. It does not replace the production hangar. Serve `dist` through the normal dev server and open `/scene/hangar-fixture.html`. The fixture uses the current live frame IDs 0, 5, 6, 7, 8, 9, 10 and 12; the fourth-seat button exercises both seat counts. Reserves invoke a fixture callback rather than the game Workshop. Gatecrasher and the other missing Phase 3 rigs are not fabricated.

`IronVowHangar.create({catalog, onSelect, onReserve})` uses `IronVowRenderer`'s existing context. `catalog.create(unit)` returns `{object, update({time, dt, selected, condition}), dispose()}`; object is a THREE.Object3D and catalog owns all rig resources. Returning a holder that fills asynchronously permits on-demand rigs. `setRoster({active, reserve, seatCount})` maintains one pad per seat including empty seats, positions reserves separately, and preserves unit IDs. `select(id)` and `pick(clientX, clientY, rect)` route active selection and reserve activation. `setHotspots([{element, position:[x,y,z]}])` and `placeHotspots(rect)` project caller-owned HTML. `render(seconds, dtSeconds, width, height)` renders on the shared context; `dispose()` releases scene-owned objects and asks the catalog to dispose rigs. Condition is normalized from 0 to 1; the caller is responsible for rig scorch materials while the scene adds a scorch mark and gantry below .3.

The fixture demonstrates existing procedural and adapter rigs, occasional selected look-around, workers, welding light and sparks, light shafts, beacons, dust, crane, camera easing and HTML projection. It is intentionally unintegrated: Phase 3 must deliver all rig-v2 assets and a production catalog first; hook actual save seats, Workshop navigation, facilities, Ship and Crew Cabin into the caller, validate conditions and context restoration, run visual/interaction and iPad performance checks, and only then remove the existing backdrop and rain renderer. No device performance or full Phase 4 completion is claimed. The base checkout includes SHOGUN at stable frame ID 20; this module does not enumerate or modify frame IDs.
