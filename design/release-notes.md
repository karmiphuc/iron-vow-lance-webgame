# Last Light playability release

The visual rebuild replaces primitive block mechs with detailed original 2.5D art: three distinct chassis, a rain-lit hangar, individual pilots, contract environments and matching battlefield terrain/cover. Native weapon effects and camera response remain driven by live combat state.

This release also adds active-sortie checkpoints, replayable interrupted enemy phases, improved mobile subsystem selection, a viable emergency repair path, and save compatibility beyond pilot level 99.

Verification: JavaScript syntax, DOM interactions, native canvas image loading/rendering, complete missions, an earned-money career ladder and reload/recovery scenarios passed. Browser visual QA remains blocked by the missing supported browser tool; visual fidelity is not certified.
